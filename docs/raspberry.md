# Raspberry: qual programa usar

O agente `raspberry/capture_and_send.py` do início do projeto captura e envia fotos. A missão de oito fotos da bancada usa outro programa, `tcc_integrado.py`, com módulos de movimento, visão e registro e com a configuração de percurso da placa.

Consulte [Operação da Raspberry](operacao-raspberry.md) para identificar os arquivos ativos e a unidade de partida automática. Para transferir o código do protótipo, use o [procedimento de coleta](sincronizar-bancada.md). A troca do detector da V1 para a V2 ocorre no servidor.
